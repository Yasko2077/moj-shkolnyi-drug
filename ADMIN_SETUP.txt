Ынтымак 0.9 — ОДНА АДМИНИСТРАТИВНАЯ УЧЁТНАЯ ЗАПИСЬ

1) Публичная форма авторизации общая. Администратор регистрируется по email так же, как остальные пользователи.
2) Взрослый владелец/координатор подтверждает email, затем назначает эту учётную запись администратором через Supabase SQL Editor.
3) Требуется уже применённая миграция supabase/schema_mvp07.sql, в ней создаётся public.platform_admins с ограничением singleton=true и RPC public.is_platform_admin().
4) Запрос назначения (подставить email):

insert into public.platform_admins(singleton, user_id)
select true, id
from auth.users
where lower(email) = lower('ADMIN_EMAIL_HERE')
  and email_confirmed_at is not null;

5) Не создавать вторую admin-учётную запись. Не хранить пароль в коде/чате. Не использовать service_role/sb_secret в браузере.
6) Раздел «Управление» отображается только если серверная проверка is_platform_admin() вернула true.
7) В демо-версии управление работает только с локальными тестовыми данными браузера. Это не централизованная админ-панель для реального пилота.
